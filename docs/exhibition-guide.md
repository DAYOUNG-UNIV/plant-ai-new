# 쫑알쫑알 화분 전시 열람본 — 먼저 읽어 주세요

이 패키지는 저장된 기록과 설명을 보여 주는 정적 전시 열람본입니다. 실제 센서 기록의 측정일과 자료 구분은 화면에 표시된 내용을 확인해 주세요. 인터넷이 끊겨도 새 센서 값이나 AI 답변이 생성되는 것은 아닙니다.

## 전날 준비

1. 전시 ZIP을 내려받아 **전체 압축 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
2. 노트북에서 `tablet.html` 또는 `index.html`을 브라우저로 열어 자료가 보이는지 확인합니다.
3. 직접 파일 열기가 제한되면 아래의 로컬 서버를 사용합니다. Python 3.9 이상이 미리 설치되어 있어야 하며 3.12를 권장합니다. 실행 파일은 Python이나 추가 패키지를 내려받지 않습니다.
4. 태블릿에서 사용할 PDF가 패키지에 있으면 미리 내려받고 비행기 모드에서도 열리는지 확인합니다.
5. 전시장과 같은 방식으로 노트북·태블릿을 연결한 뒤 인터넷을 끊어 화면이 유지되는지 확인합니다. 노트북 절전도 꺼 둡니다.

## 노트북에서 열기

압축을 푼 폴더의 **start-exhibit.cmd**를 두 번 클릭합니다. 표시된 주소 `http://127.0.0.1:8765/`를 브라우저에서 엽니다.

실행 창을 닫으면 서버도 종료됩니다. 종료하려면 실행 창에서 **Ctrl+C**를 누릅니다. 기본 설정은 이 노트북에서만 접속할 수 있습니다.

명령어로 실행할 수도 있습니다.

```powershell
py -3.12 serve_exhibit.py --directory . --open
```

프로젝트 원본 폴더에서는 `start-exhibit.cmd`가 `artifacts/exhibition` 열람본을 찾습니다. 개발용 앱이나 가상환경을 실행하는 명령이 아닙니다.

## 같은 Wi-Fi의 태블릿에서 열기

노트북과 태블릿을 같은 Wi-Fi나 직접 준비한 공유기에 연결합니다. **인터넷 접속이 없어도 두 기기 사이의 네트워크 연결은 필요합니다.**

노트북에서 다음과 같이 실행합니다.

```powershell
.\start-exhibit.cmd --lan
```

실행 창의 **Same-Wi-Fi tablet** 주소를 태블릿 브라우저에 입력합니다. 여러 주소가 표시되면 현재 사용 중인 Wi-Fi의 IPv4 주소를 선택하세요. 이 주소는 노트북의 네트워크 상태에 따라 달라집니다.

접속되지 않으면 같은 네트워크인지, Windows 방화벽에서 해당 사설 네트워크의 접근이 허용되어 있는지, 행사장 Wi-Fi가 기기 사이 통신을 차단하는지 확인합니다. 행사장 Wi-Fi가 기기 통신을 막는 경우 미리 준비한 공유기·핫스폿을 시험해야 합니다. 노트북 전원과 서버 창은 계속 켜 둡니다.

서버는 선택한 전시 폴더의 허용된 정적 파일만 읽기 전용으로 제공합니다. API 키가 필요하지 않으며 업로드·수정 기능은 없습니다. 다른 사람도 자료를 볼 수 있는 LAN 모드는 전시용 네트워크에서 필요할 때만 사용하세요.

## 태블릿 한 대만 들고 갈 때

- **Android:** 파일을 내려받고 브라우저로 `tablet.html`을 열 수 있는지 해당 기기에서 미리 확인합니다. 파일 관리자·브라우저 조합에 따라 직접 열기가 다를 수 있습니다.
- **iPad:** 파일 앱의 HTML 미리보기에서 JavaScript가 실행된다고 보장할 수 없습니다. 인터랙션이 작동하지 않으면 노트북의 동일 Wi-Fi 서버를 이용하세요.
- **완전한 오프라인 열람:** 패키지의 `offline-guide.pdf`가 있으면 기기에 저장해 사용합니다. PDF는 설명과 캡처를 읽는 용도이며 대화·차트 조작 기능은 없습니다.

홈 화면에 추가했다고 모든 브라우저에서 오프라인 앱이 되는 것은 아닙니다. 일반적인 서비스 워커 기반 오프라인 설치에는 HTTPS 또는 해당 기기의 localhost 같은 보안 출처가 필요합니다. 태블릿에서 접속한 `http://192.168... ` 등의 LAN 주소만으로 설치와 캐시를 보장하지 않습니다. HTTPS 게시를 따로 준비한 경우에는 설치 후 비행기 모드 검증을 마친 기기만 독립형 열람 기기로 사용하세요.

## 문제가 생기면

- **Python을 찾을 수 없음:** 실행기는 자동 설치하지 않습니다. 미리 준비한 Python을 사용하거나 직접 HTML·PDF 열람으로 전환합니다.
- **포트가 사용 중:** `.\start-exhibit.cmd --port 8766`으로 실행하고 새로 표시된 주소를 사용합니다.
- **파일을 찾을 수 없음:** 모든 파일을 함께 압축 해제했는지 확인합니다. 서버의 `--directory`에는 전시 폴더를 명시해야 합니다.
- **오래된 자료가 보임:** 이 열람본은 제작 시점의 저장 자료입니다. 새 기록 반영에는 전시 패키지를 다시 제작해야 합니다.
- **인터넷이 끊김:** 같은 Wi-Fi 내 노트북 서버 접속은 인터넷과 별개입니다. Wi-Fi 연결까지 끊겼다면 미리 저장한 PDF로 전환합니다.

전시장에서는 저장 자료, 과거 재생, 실제 새 측정과 실시간 AI 응답을 서로 구분해 설명해 주세요.


## 3분 체험 진행 예시

1. **30초 — 시간 찾기:** 자료의 구분과 마지막 측정 시각을 함께 읽습니다. 측정이 멈춘 자료라면 현재 화분의 실시간 상태가 아님을 설명합니다.
2. **1분 — 기록 읽기:** 온도·공기 습도·토양 센서의 단위를 비교하고 그래프의 빈 구간을 찾습니다. 실제 자료가 연결되지 않은 준비본에서는 기록 관찰을 건너뛰고 아래의 시간·단위 미션을 진행합니다.
3. **1분 — 탐구 미션:** 관람객이 정답을 고르고 설명을 읽습니다. 토양 원시값을 공기 습도 퍼센트로 해석하지 않는지 확인합니다.
4. **30초 — 돌아보기:** 저장된 질문 안내에서 한 질문을 고른 뒤 체험 초기화 버튼으로 다음 관람객을 준비합니다.

오프라인 체험의 답변은 저장된 기록으로 미리 계산한 안내입니다. Gemini가 그 자리에서 새 답변을 만든다고 소개하지 마세요.
