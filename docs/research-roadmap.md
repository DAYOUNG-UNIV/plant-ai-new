# 연구계획서와 연결한 확장 · 2026-10-04

## 이번 검토의 기준

로컬 연구계획서 「장기 시계열 사물인터넷 데이터를 활용한 다중 감각 기반 공간 에이전트 인터페이스 설계 및 실증」, 스마트라이프위크 부스 제안서, 마포 스마트팜 AI 탐구안내 정책 제안서를 읽고 설계했다. 원본 PDF와 문서의 연락처·개인정보는 이 저장소에 복사하지 않았다.

연구계획서는 데이터 전처리·동적 도구 할당·XR 연결·대조군 및 혼합 방법 평가를 요구한다. 전시 제안서는 현장 Arduino 수집 없이 사전 축적 기록으로 운영하는 구성을 제시한다. 정책 제안서는 실제 대상을 관찰한 뒤 질문하는 흐름, 로컬 핵심 활동, 설명 수준 조절, 연구 수집의 별도 절차를 제시한다. 따라서 마지막 관측일과 실제 현재를 분리하는 기존 설계를 유지한다.

## 적용한 기능과 연구 질문

| 연구 목표 | 구현 | 검증할 질문 / 한계 |
|---|---|---|
| 필요한 함수만 선택하는 데이터 접근 | 명확한 질문은 결정적 조회 계획으로 선조회하고 관련 도구만 제공. 불명확한 질문은 전체 읽기 도구 유지 | 도구 수·호출 수·토큰·기간 정확도. 규칙 기반 한국어 계획이며 학습된 라우터가 아님 |
| 근거에 맞는 응답 | 질문 범위와 도구 인자에 맞는 성공/빈 결과/실패를 구분하는 실행 감사, 근거 ID와 구조화 카드 | 조회 실행 검증과 자연어 사실성은 별개. 모든 문장에 대한 환각 검출을 보장하지 않음 |
| 간헐적 센서 수집 | 관측 평균 외에 공백을 제외한 시간 가중 평균·지원 시간·최대 공백 표시 | 10분 이하 간격만 계단근사. 장기 중단이나 마지막 값 외삽 금지. 식물 생리 추정 아님 |
| 짧은 변화가 보이는 시각화 | 구간별 최소·최대·평균과 공백 표시 | 극값을 보존하지만 원본의 모든 파형을 복원하는 차트는 아님 |
| 실제 식물 관찰과 추가 질문 | 관찰 → 기록 카드 → 질문 → 이해 확인의 세 미션, 바질/해설자와 쉬운 설명 | 버튼은 자기보고이며 실제 시선·집중·식물 상태 측정이 아님 |
| 실증을 준비할 운영 점검 | 명시적으로 시작하는 리허설 기록, 통제된 이벤트만 JSON 내보내기 | 실제 참여자 연구의 동의·조건 배정·설문·윤리 절차를 대체하지 않음 |

이번 변경은 웹 기반 연구 프로토타입이다. 광학식 안경의 대상 인식, 공간 고정 표시, 음성 전사, 장기 사용자 연구는 구현 완료로 주장하지 않는다.

## 최신 논문과 기술 검토

확인일 2026-10-04. 아래 논문의 방법·모델을 재현했다고 주장하지 않으며, 설계와 평가 항목을 도출하는 데 참고했다.

- **[Closed-World Resolution Against Tool Hallucination (2026-09-16, arXiv)](https://arxiv.org/abs/2609.19425)**: 존재하지 않는 도구와 선언되지 않은 인자 문제를 다룬 측정·벤치마크 연구다. 기존 허용 목록·스키마 검증을 유지하면서 질문별 도구 범위를 추가했다. 이 논문의 HTB 벤치마크를 실행하거나 자연어 환각을 모두 검증한 것은 아니다.
- **[AgentHallu (2026-01-11, arXiv)](https://arxiv.org/abs/2601.06818)**: 다단계 에이전트의 오류 발생 단계를 식별하는 평가 문제를 제시한다. 여기서는 도구별 실패와 근거 ID를 남기는 설계 관점만 참고하며 논문의 자동 귀인 평가기를 재현하지 않았다.
- **[TimeART (2026-01-20, arXiv)](https://arxiv.org/abs/2601.13653)**: 시계열 분석 도구와 언어모델의 추론을 결합하고 도구 사용 궤적으로 모델을 학습한 연구다. 이 프로젝트에는 계산을 Python에 맡기는 방향을 적용한다. 해당 모델 학습이나 10만 건 코퍼스 재현은 하지 않았다.
- **[TSAQA (2026-01-30, 6월 개정)](https://arxiv.org/abs/2601.23204)**: 다양한 시계열 분석 질문을 평가한다. 평균만 묻는 데서 벗어나 비교·추세·변화 위치·조회 불가 질문을 분리해서 평가한다. ACL 2026 GEM 워크숍 채택으로 표기하며 ACL 본회의 논문으로 소개하지 않는다.
- **[TS-Skill (2026-05-23, arXiv)](https://arxiv.org/abs/2605.24703)**: 시간 규모 선택, 시간 위치 찾기, 분리된 구간의 통합을 나누어 평가한다. 이 구분을 기간·기준일·구간 비교 회귀 사례에 적용한다. 자체 질문 세트는 공식 TS-Skill 점수가 아니다.
- **[ChatTS (PVLDB 2025)](https://www.vldb.org/pvldb/vol18/p2385-xie.pdf)**: 시계열을 언어모델과 연결하는 이해·추론 연구다. 현재의 작은 전시 앱에서는 대형 시계열 모델을 탑재하기 전에, 원본 극값·공백과 계산 근거를 보존하는 조회 계층을 우선한다.
- **[Anthropic, Demystifying evals for AI agents (2026-01-09)](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)**: 도구 호출과 최종 결과를 구분하고 코드 평가와 사람 평가를 함께 사용하는 공식 기술 문서다. 학술 논문과 구별한다. 이 앱도 결정적 조회 검증, 실제 모델 문장의 사람 검토, 사용자 경험 연구를 따로 둔다.
- **[Talk2Agent (2026-09-30, arXiv)](https://arxiv.org/abs/2609.38867)** 및 **[τ-Voice (2026-03, arXiv)](https://arxiv.org/abs/2603.13686)**: 음성 확장 시 전사 정확도만 보지 않고 날짜·대상·단위 보존 및 작업 성공을 평가할 근거다. 전시장의 한국어 음성·기기 성능은 아직 측정하지 않았다.
- **[PlantMate (CHI EA 2025)](https://exertiongameslab.org/wp-content/uploads/2025/04/plantmate_chi2025.pdf)**: 식물과의 상호작용을 탐색한 선행 사례다. 이 시스템의 교육·정서 효과를 입증하는 근거로 전용하지 않는다.

## 에이전트 기술의 채택과 보류

채택한 것은 의도에 따른 도구 선택, 제한된 실행 예산, 구조화된 근거, 실행 감사, 오프라인 회귀 평가다. 명확한 조회를 미리 실행하므로 계획 생성용 LLM 호출을 별도로 추가하지 않는다. 근거 카드와 실행 감사는 모델의 숨은 추론을 저장하지 않는다.

멀티 에이전트 토론이나 별도 판정 LLM은 현재 보류한다. 세 센서와 작은 가이드에 추가 호출·지연을 들이는 것보다 Python 정답과 조회 기간을 대조하는 편이 먼저 검증 가능하다. MCP/A2A는 외부 도구 서버나 다른 장비와의 연결이 필요해질 때 검토한다. 현재 같은 프로세스의 읽기 함수에 프로토콜을 추가하는 것만으로 연구 기여가 생기지는 않는다.

Chronos-2 등 예측 모델도 보류한다. 실제 원시 기록의 수집 중단, 센서 보정, 물주기·분갈이·센서 이동 사건이 확인되지 않아 예측 목표와 정답을 먼저 정의해야 한다. 이후 마지막 값·계절성 기준모델과 시간 순서로 나눈 검증을 수행한다.

## 재현 가능한 평가 순서

1. **계산 검증:** 기간 경계, KST, 중단, 중복, 결측, 시간 가중 평균, 극값 보존을 단위 테스트한다.
2. **워크플로 평가:** 고정 합성 기록과 작성된 질문 세트로 질문 계획·실행 근거·명시된 정답 수치를 확인한다. 실제 Gemini 성능으로 부르지 않는다.
3. **실제 모델 평가:** 같은 질문과 모델 버전을 고정해 여러 번 실행하고 기간 오류, 지원되지 않은 수치, 오래된 값을 현재로 표현한 비율, 근거 인용, 지연·호출·토큰을 수집한다. 아직 키 연결 후 수행할 단계다.
4. **비교 실험:** 동일 센서 자료/가이드/질문으로 기록 카드, 기존 도구형 대화, 계획+감사 대화를 비교한다. 라우팅과 감사를 각각 제거한 조건을 포함해야 각 기여를 구분할 수 있다.
5. **HCI 연구:** 설명 이해·회상·돌봄 판단·자발적 질문과 실제 관찰 행동을 평가한다. 리허설의 버튼 로그만으로 실제 관찰 시간·정서적 친밀감을 주장하지 않는다. 순서 효과, 자기보고 편향, 체험자 선정 편향을 통제한다.

실제 연구 수집은 전시 운영과 구분한다. 현재 앱의 리허설은 운영자가 명시적으로 시작한 세션의 버튼 및 성능 지표만 메모리에 유지하며, 다운로드 전 서버 파일이나 외부 분석 서비스에 저장하지 않는다. 질문·답변·음성·성명은 리허설 내보내기 대상이 아니다. 일반 대화는 화면 표시를 위해 해당 Streamlit 세션 메모리에 남는다.

## 기존 기반과 다음 과제

- 인덱스 조회 성능은 동일 계산의 결과 동등성부터 확인한다. 합성 20만 행 측정은 Google Sheets 다운로드나 LLM 응답 지연을 포함하지 않는다.
- 현재 Google Sheets 연결은 전체 CSV 재다운로드다. 장기 운영을 위해 증분 동기화·서버 저장소와 세션 간 데이터 버전 관리가 남아 있다.
- RAG는 사용자 작성 JSON의 로컬 어휘 검색이다. 농업 전문가/공공기관 자료 검수, 승인 버전과 변경 이력, 별도 검색 정답 세트가 다음 단계다.
- Meta Ray-Ban Display는 실제 기기에서 한국어 입력·음성·네트워크·화면 배치를 확인한 후 별도 클라이언트로 연결한다. 웹 개선을 안경 연동 완료로 표현하지 않는다.
